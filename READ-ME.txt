ВИЗИТКА · МИНИ-ИГРА И ТОП-3

Сначала установи обновление сервера из DONT-CRY-LEADERBOARD.zip.
Затем на GitHub → mysite → Add file → Upload files загрузи index.html, light-game.css и light-game.js. Подтверди Commit changes. Сам ZIP не загружай.
Обнови сайт после публикации.

В «Треки» две кнопки: стрелки меняют направление, круг включает последовательное повторение списка. Серый круг = случайный выбор. Синий круг = по порядку, направление задаёт первая кнопка.
В мини-игре после раунда укажи ник и нажми «В топ-3». Ник публичный, вход в аккаунт не нужен. Одинаковый ник считается одной записью; сохраняется лучший результат. Ники не защищены от использования другим человеком.
Личный рекорд остаётся в браузере. Общий рейтинг хранится на сервере. При недоступности сервера можно играть без рейтинга.

Проверены синтаксис, сборка сервера, проверка источника запросов, повторных попаданий и повторной отправки раунда. Проверки на реальных телефонах и браузерах не выполнялись. Ограничения результатов не являются полной защитой от автоматизации.
